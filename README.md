# Cabin

A fast, simple, pure Rust terminal file manager with a three-pane UI.

## Status

Early development.

## Install

```powershell
cargo install --path .
```

That gives you terminal commands:

- `cabin`
- `cab`

## v0.1

- Launches in the terminal
- Shows Places, Contents, and Preview panes
- Starts in the user's home directory
- Navigates folders
- Shows file and folder metadata
- Restores the terminal cleanly on exit
